# Workload B: micro-LLM one-shot prompt set

Generated by: `bench/make-prompts.sh` (deterministic, from corpus-v1).

Shape: 100 prompts, JSONL `{id, prompt}`. Each prompt is an intent-classification
one-shot over a real code chunk (the class of call AFT/MC would send: single-shot,
structured output, no conversation):

    Classify the primary purpose of this code chunk. Answer with exactly one word
    from: config, test, logic, io, types, docs.

    <chunk text, truncated to ~300 tokens>

Lane contract for workload B:
- temperature 0 (greedy), max 16 new tokens, no system prompt, no chat history.
- Report: cold_load_s (process start -> first token of first prompt available),
  infer_wall_s (all 100 prompts), input_tokens (prompt tokens), plus generated
  tokens and decode tok/s in notes.
- Output validity: fraction of answers that are one of the six labels (reported in
  notes) — catches runtimes that produce garbage fast.
