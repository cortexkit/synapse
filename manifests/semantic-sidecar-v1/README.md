# Semantic-sidecar manifest pointer

The frozen semantic-sidecar measurement manifest is retained under `evidence/semantic-sidecar-v1/measurement-contract-v1.json` with its digest sidecar. The source request partitions remain intentionally unbound because the production-shaped athena-classify and dreamer inputs are not hydrated in this worktree. A future run must create a new immutable successor manifest rather than inserting request IDs into this pointer revision.
