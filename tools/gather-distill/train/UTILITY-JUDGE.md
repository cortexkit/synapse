# Utility judge evaluation

This report is generated by the `judge` lane after the calibration gate passes. It deliberately measures downstream utility rather than agreement with Opus citations: the headline metric is the number of additional AFT tool calls needed after the package is supplied. Gold-overlap file F1 is shown alongside it as a contrast metric.

## Run protocol

The judge receives only the original question and a package whose snippet pointers have been hydrated from the pinned repository. It first answers without tools. Only a non-full phase-1 result can open the same nine read-only AFT tools, with a hard cap of 15 calls. Every call and its returned bytes are retained in the ignored verdict JSONL files.

Use the exact GPT-compatible endpoint and key supplied for the run; do not substitute the Anthropic OAuth pool. The operator can set `JUDGE_BASE_URL`, `JUDGE_API_KEY`, `JUDGE_MODEL`, and optional `JUDGE_KEY_HEADER` instead of passing flags:

```sh
bun run src/cli.ts judge \
  --phase calibration \
  --jobs data/eval-jobs.jsonl \
  --gold data/eval-gold-rows.jsonl \
  --candidate qwen35-4b-lora-v1=data/students/qwen35-4b-lora-v1-rows.jsonl \
  --candidate qwen35-9b-lora-v1=data/students/qwen35-9b-lora-v1-rows.jsonl \
  --base-url "$JUDGE_BASE_URL" \
  --api-key "$JUDGE_API_KEY" \
  --input-usd-per-million INPUT_RATE \
  --output-usd-per-million OUTPUT_RATE
```

Calibration uses the first five jobs and runs three blind controls per job: the matching gold package, an interpretation-only empty package, and a package from a different question. The gate requires gold mean top-up below two calls, empty mean above eight calls, and at least 60% of mismatches classified as none. If it fails, stop; rerun calibration with `--prompt-iteration 2` or `3` after changing the prompt, and keep the reported prompt SHA/change with the evidence.

After the gate passes, run the full matrix. The command writes `data/students/judge/<label>-verdicts.jsonl` and `gold-control-verdicts.jsonl`; pass each existing score report as `--score LABEL=PATH` so the generated table includes natural-completion F1. Full runs judge only natural, valid packages. Invalid or forced rows are recorded as `sufficiency=none` without spending judge calls and are counted separately.

```sh
bun run src/cli.ts judge \
  --phase full \
  --jobs data/eval-jobs.jsonl \
  --gold data/eval-gold-rows.jsonl \
  --candidate qwen35-4b-lora-v1=data/students/qwen35-4b-lora-v1-rows.jsonl \
  --candidate qwen35-9b-lora-v1=data/students/qwen35-9b-lora-v1-rows.jsonl \
  --score qwen35-4b-lora-v1=data/students/qwen35-4b-lora-v1-scores.json \
  --score qwen35-9b-lora-v1=data/students/qwen35-9b-lora-v1-scores.json \
  --base-url "$JUDGE_BASE_URL" \
  --api-key "$JUDGE_API_KEY"
```

The calibration report estimates token spend from the five-job sample. If endpoint-specific rates are supplied and the projected full run exceeds the `$30` default quota, the full phase stops before making judge calls. The report records model ID, prompt SHA, temperature, and the 15-call budget on every verdict row.

Once credentials exist, the two runnable one-liners are:

```sh
JUDGE_BASE_URL='https://the-confirmed-endpoint/v1' JUDGE_API_KEY='...' bun run src/cli.ts judge --phase calibration --jobs data/eval-jobs.jsonl --gold data/eval-gold-rows.jsonl --candidate qwen35-4b-lora-v1=data/students/qwen35-4b-lora-v1-rows.jsonl --candidate qwen35-9b-lora-v1=data/students/qwen35-9b-lora-v1-rows.jsonl --candidate deepseek-v4-flash-zeroshot=data/students/deepseek-v4-flash-zeroshot-rows.jsonl
JUDGE_BASE_URL='https://the-confirmed-endpoint/v1' JUDGE_API_KEY='...' bun run src/cli.ts judge --phase full --jobs data/eval-jobs.jsonl --gold data/eval-gold-rows.jsonl --candidate qwen35-4b-lora-v1=data/students/qwen35-4b-lora-v1-rows.jsonl --candidate qwen35-9b-lora-v1=data/students/qwen35-9b-lora-v1-rows.jsonl --candidate deepseek-v4-flash-zeroshot=data/students/deepseek-v4-flash-zeroshot-rows.jsonl --score qwen35-4b-lora-v1=data/students/qwen35-4b-lora-v1-scores.json --score qwen35-9b-lora-v1=data/students/qwen35-9b-lora-v1-scores.json --score deepseek-v4-flash-zeroshot=data/students/deepseek-v4-flash-zeroshot-scores.json
```

The deepseek candidate is optional: omit that assignment when its rows have not landed in `data/students/`.
